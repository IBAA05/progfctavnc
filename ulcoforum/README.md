
# ulcoforum

## Description

Un forum basique avec :

- une page d'accueil
- une page affichant tous les messages
- une page affichant toutes les discussions et permettant d'en sélectionner ou d'en ajouter une
- une page affichant la discussion sélectionnée et permettant d'y ajouter un message
